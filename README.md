# .github

Default community health files for every public repository under
[`jdwillmsen`](https://github.com/jdwillmsen).

GitHub serves the files here to any repository on this account that does not
carry its own copy, so `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, the code
of conduct and the issue and pull request templates are maintained in one place
instead of drifting across repositories.

A licence cannot be defaulted this way. GitHub requires `LICENSE` in each
repository so that it travels with a clone, package or download, so every
repository carries its own copy of PolyForm Noncommercial 1.0.0.

The equivalent for the `jdwlabs` organisation lives at
[`jdwlabs/.github`](https://github.com/jdwlabs/.github), which additionally
holds shared rulesets and reusable workflows. This repository deliberately holds
only community health files.
